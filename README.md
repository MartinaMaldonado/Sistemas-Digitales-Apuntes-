## Contenido Temático del Curso

### Unidad 1: Microcontroladores para sistemas embebidos *(Subido)*
* **1.1.** Introducción a los microcontroladores y al diseño de sistemas embebidos[cite: 195, 196]

* **2.5.** FreeRTOS para microcontroladores
